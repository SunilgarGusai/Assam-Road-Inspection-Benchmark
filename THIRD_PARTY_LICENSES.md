# Third-party data and materials

This repository releases only original repository code/documentation under the MIT License. External scientific datasets are **not relicensed**.

| Source | Study use | Public redistribution here |
|---|---|---|
| Sentinel-1 GRD / Copernicus | Event-specific retrospective flood-exposure mapping | No raw scenes redistributed |
| ERA5 / Copernicus Climate Data Store | Hourly precipitation features | No raw archive redistributed |
| CHIRPS | Daily rainfall sensitivity features | No raw archive redistributed |
| SRTM | Terrain/elevation support | No raw tiles redistributed |
| OpenStreetMap / Geofabrik | Dated pre-event road-network snapshots | No raw PBF snapshots redistributed |

Users should obtain each dataset from its original provider and comply with the provider's current terms. See `docs/DATA_SOURCE_MANIFEST.md`.
